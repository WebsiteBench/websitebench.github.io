Run the benchmark

/run

Requires uv and Docker. These commands set up the repository and run an agent on one task with Harbor, which fetches the task from Harbor Hub.

Run one task
git clone https://github.com/TIGER-AI-Lab/WebsiteBench.git
cd WebsiteBench
uv sync
uv run harbor run --task websitebench/medium@v1 \
  --agent codex --model '<model>' \
  --allow-environment-host snapshot.debian.org \
  --allow-environment-host deb.debian.org \
  --allow-environment-host raw.githubusercontent.com \
  --allow-environment-host github.com \
  --allow-environment-host nodejs.org \
  --allow-environment-host registry.npmjs.org
  • The repository pins Harbor 0.25.0. The 70 tasks form the Harbor Hub dataset websitebench/WebsiteBench@v1; replace --task websitebench/medium@v1 with --dataset websitebench/WebsiteBench@v1 to run all of them.
  • The same tasks are on Hugging Face. To run a task directory you have downloaded, pass --path with that directory instead of --task.
  • Set --agent and --model to the agent and model you want to evaluate.
  • Harbor installs the agent inside the task container during setup, and the task network allows only the browser there. The --allow-environment-host flags open the installer's download hosts for that step only. For Claude Code, allow snapshot.debian.org, deb.debian.org and downloads.claude.ai instead.
  • The Docker host needs Linux 6.7 or newer (Landlock ABI 4, used by the verifier's sandbox) and nftables fib support (used to enforce the task network policy).
  • Each task gives the agent up to 16 hours and the verifier up to 8 hours. Most tasks request 8 CPUs, 8 GiB of memory and 20 GiB of disk.
