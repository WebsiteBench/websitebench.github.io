A user workflow is a sequence of actions that completes a goal, such as selecting a product, adding it to a cart, checking out and viewing the order confirmation. The paper traces why agents fall short through three studies.

Human trajectory

Grok 4.6paired runs16-hour limit

A human exploration trace raised reconstruction scores. The largest gains came on websites where the agent exploring alone passed no hidden tests.

Each website is rebuilt twice, with the same model, agent and time limit
RunWhat the agent has
Explores aloneThe reference website, through the browser.
With a human traceThe same browser access, plus a read-only log of the actions a website developer took while exploring the reference. The log holds no page content, so the agent still explores with its own tools.

With the trace, agents had seen the final result of more workflows before their first code edit. People also explore far faster than agents: a recorded human session lasts minutes and visits more distinct pages than an agent reaches in hours of exploration.

Exploration and implementation

Grok 4.6one run per website

By their first code edit, agents had visited nearly every core page and started nearly every core workflow, but few workflows had reached their final result.

We also checked requirements that the agent had observed and that its trajectory and submitted code let us verify: page contents, workflows and persisted state. Almost none were implemented the way the reference behaved. Most tool calls explored the reference or checked the rebuild, and a small share edited code.

Early stopping

16-hour limitone continuation case

Most runs in the main experiments ended well before the 16-hour limit.

In a Kimi K3 rebuild of Lowe’s, Claude Code’s /goal hook reviewed each attempt to stop. At 10.25 hours the agent declared its repairs complete; the hook rejected the exit, and the agent went on to check that cart, order, account and session state survived a restart. The run ended at 10.9 hours instead of 1.0, and the score rose from 0% to 31.3%.
