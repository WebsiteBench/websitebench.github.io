Three ways the rebuilds go wrong

1Underexploration

Agents visit the pages but seldom follow a workflow to its end

By their first code edit, agents had started nearly every core workflow but followed only a few to the end.

A human exploration trace raised scores most where the agent alone had passed no hidden tests.

2Failure to implement observed behavior

What agents observe rarely reaches their code

Almost none of the behaviors agents observed were implemented the way they saw them.

Most tool calls explored the reference or checked the rebuild. Few edited code.
