# Model brand marks

Monochrome SVGs vendored from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), with the upstream license in this folder. Files: anthropic.svg, openai.svg, xai.svg, zai.svg, kimi.svg, deepseek.svg, qwen.svg. Logos identify the organization or model family; adjacent model names distinguish individual models. No external asset requests are needed at runtime.
